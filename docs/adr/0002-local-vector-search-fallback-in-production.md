# Rank embeddings in-process when MongoDB has no vector search

Railway's managed MongoDB is Community Edition and has no `$vectorSearch`, while local development uses MongoDB Atlas Local, which has it. The backend therefore supports two retrieval modes selected with `VECTOR_SEARCH_MODE`: `atlas` runs `$vectorSearch` against a vector index, and `local` loads the stored embeddings and ranks them by cosine similarity in Python, skipping index creation. We accepted the extra code path because the menu and knowledge collections hold only a few dozen documents, which keeps production on the managed database without paying for an external Atlas cluster or running a self-hosted search engine. The `local` mode scans every document per query, so moving to a larger corpus means switching back to `atlas` mode on a database that supports it.
